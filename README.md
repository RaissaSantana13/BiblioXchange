O **BiblioXchange** é uma plataforma web dedicada à facilitação da troca de livros entre leitores. O projeto foca-se em criar uma comunidade onde utilizadores podem disponibilizar as suas obras e encontrar novas leituras na sua proximidade.

---

## Funcionalidades Principais

* **Sistema de Autenticação:** Página de login intuitiva com validação de e-mail e palavra-passe, incluindo suporte para recuperação de conta e alternância de visibilidade da senha.
* **Vitrine de Livros:** Uma galeria organizada que apresenta livros disponíveis para troca "por perto", exibindo capas, títulos e botões de ação para mais detalhes.
* **Pesquisa Dinâmica:** Barra de busca centralizada que permite filtrar obras por título, autor ou género literário.
* **Gestão de Perfil:** Menu dropdown interativo que oferece acesso rápido às definições da conta, lista de livros pessoais e opção de logout.
* **Interface Moderna:** Design limpo e responsivo utilizando a tipografia *Inter* e ícones da biblioteca *Font Awesome*.

---

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todas as páginas, desde o login até à vitrine de exposição.
* **CSS3:** Estilização personalizada através de múltiplos ficheiros (`main.css`, `vitrine.css`, `style_books.css`) para garantir uma identidade visual coesa.
* **JavaScript (Vanilla):** Implementação de lógica de interface, como o comportamento do menu de perfil e interações de formulário.
* **Recursos Externos:** Integração com **Google Fonts** e **Font Awesome** para uma experiência de utilizador enriquecida.

---

## Estrutura do Projeto

* `index.html`: Portal de entrada e formulário de acesso ao sistema.
* `vitrine.html`: Página principal onde o utilizador explora os livros disponíveis na rede.
* `script.js`: Gestão de eventos globais e interatividade da interface.
* `Livros/`: Diretório que contém as páginas de detalhes específicos para cada obra (ex: `livro1.html`, `livro2.html`).
* `Media/`: Repositório de assets visuais, incluindo capas de livros e ícones.

---

## Como Funciona a Troca

1.  O utilizador acede à plataforma através da página de **Login**.
2.  Navega pela **Vitrine** para descobrir obras de interesse como "Lady Killers", "Moby Dick" ou "A Biblioteca da Meia-Noite".
3.  Utiliza o botão **"Saiba Mais"** para visualizar detalhes adicionais da obra e do proponente da troca.
4.  Gere as suas preferências e livros através do **Menu de Perfil** no canto superior direito.

# BiblioXchange

**BiblioXchange** is a web platform dedicated to facilitating book exchanges between readers. The project focuses on creating a community where users can share their books and find new reads nearby.

---

## Main Features

* **Authentication System:** Intuitive login page with email and password validation, including support for account recovery and password visibility toggling.
* **Book Showcase:** An organized gallery presenting books available for exchange "nearby," displaying covers, titles, and action buttons for more details.
* **Dynamic Search:** Centralized search bar that allows filtering works by title, author, or literary genre.
* **Profile Management:** Interactive dropdown menu offering quick access to account settings, personal book lists, and a logout option.
* **Modern Interface:** Clean and responsive design utilizing the *Inter* typography and icons from the *Font Awesome* library.

---

## Technologies Used

* **HTML5:** Semantic structuring of all pages, from login to the showcase gallery.
* **CSS3:** Custom styling through multiple files (`main.css`, `vitrine.css`, `style_books.css`) to ensure a cohesive visual identity.
* **JavaScript (Vanilla):** Implementation of UI logic, such as profile menu behavior and form interactions.
* **External Resources:** Integration with **Google Fonts** and **Font Awesome** for an enriched user experience.

---

## Project Structure

* `index.html`: Entry portal and system access form.
* `vitrine.html`: Main page where users explore available books in the network.
* `script.js`: Management of global events and interface interactivity.
* `Livros/`: Directory containing specific detail pages for each work (e.g., `livro1.html`, `livro2.html`).
* `Media/`: Repository for visual assets, including book covers and icons.

---

## How Exchange Works

1. The user accesses the platform via the **Login** page.
2. Browses the **Showcase** to discover books of interest such as "Lady Killers," "Moby Dick," or "The Midnight Library."
3. Uses the **"Learn More"** button to view additional details about the book and the exchange proponent.
4. Manages preferences and books through the **Profile Menu** in the top right corner.
